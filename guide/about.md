# その他

## アップデート

新しいバージョンが出ると、PCSX2 の起動時に自動で更新します。設定やメモリーカードはそのまま残ります。

ゲーム画面に「PLEASE UPDATE PCSX2」と出たときは、PCSX2 を再起動して更新してください。
ヘルプ → 更新を確認... からも更新できます。

## クラッシュレポート

PCSX2 がクラッシュすると、原因を調べるためのレポートを開発者に送ります。
ログや設定が含まれます (フォルダのパスなどは除きます)。
送りたくないときは、設定 → zdxsv の「クラッシュレポートを送信」をオフにしてください。
