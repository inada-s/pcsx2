# インストール (Windows)

### 1. ダウンロードする

下のボタンを押すと、最新版の `pcsx2-zdxsv-windows-x64.zip` がダウンロードされます。

<div class="choices"><a href="https://github.com/inada-s/pcsx2/releases/latest/download/pcsx2-zdxsv-windows-x64.zip">ダウンロード (Windows 64bit)</a></div>

### 2. zip を展開する

ダウンロードした zip を右クリックして「すべて展開」を選び、
展開先に `C:\Games\pcsx2-zdxsv` のようなフォルダを指定します。

{% include shot.html file="win-extract.png" alt="展開先のフォルダを入力して「展開」を押す" %}

> zip をダブルクリックして中のファイルを直接起動しないでください。設定が保存されません。
> `Program Files` の中にも置かないでください。
> フォルダの中の `portable.txt` は消さないでください。

### 3. 起動する

展開したフォルダ (例: `C:\Games\pcsx2-zdxsv`) を開きます。
たくさんのファイルの中から、青いアイコンの **`pcsx2-qt`** を探してダブルクリックします。

{% include shot.html file="win-folder.png" alt="展開したフォルダの中の pcsx2-qt をダブルクリックする" %}

「Windows によって PC が保護されました」と表示されたら、「詳細情報」を押してから「実行」を押します。

{% include shot.html file="win-smartscreen.png" alt="「詳細情報」を押すと出る「実行」ボタンを押す" %}
