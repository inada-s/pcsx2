# 遊び方と設定

## おすすめ設定

設定 → zdxsv に、PC の性能に合わせたおすすめ設定のボタンが 3 つあります。
対戦中にゲームが重くなるときは「低スペック PC 向け」を押してください。

{% include shot.html file="settings-zdxsv.png" alt="設定 → zdxsv のおすすめ設定ボタン" %}

同じページで、ほかにも次の設定ができます。

- 「ワイドスクリーンパッチを有効化」: 16:9 の画面にします。
- 「僚機の耐久力を表示」: 自分の耐久力の横に僚機の耐久力を出します。
- 「通信メッセージの同時押しボタン」: 右スティックがなくても、スタートボタン + 方向キーで通信メッセージを送れます。

## ネットワーク

PCSX2 の「ネットワーク & HDD」の設定は要りません。

対戦相手とつながらないときは、ルーターで UDP ポートを自分の PC に転送してください。
ポート番号は 設定 → zdxsv の「対戦用 UDP ポート」にあります。
UPnP に対応したルーターなら、PCSX2 が自動で転送します。

## オンライン中に使えない機能

ロビーと対戦中は、一時停止、早送り、ステートセーブ・ロード、リセットなど、
対戦を乱す機能は使えません。

## アカウント

設定 → zdxsv → アカウント で、Discord のサインインと、使う ID の切り替えができます。

{% include shot.html file="settings-account.png" alt="設定 → zdxsv → アカウント" %}

PS2 で遊んでいる ID は「PS2 から引き継ぐ」で PCSX2 でも使えます。
PS2 のケネディポートのロビーのチャットに ｄｃ と入力し、表示されたコードを 3 分以内に入力します。

## リプレイ

ツール → zdxsv リプレイ で、自分の対戦 (ローカル) とサーバーの対戦 (リモート) を再生できます。
