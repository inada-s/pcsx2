# インストール (Mac)

### 1. ダウンロードする

下のボタンを押すと、最新版の `pcsx2-zdxsv-macos.tar.xz` がダウンロードされます。

<div class="choices"><a href="https://github.com/inada-s/pcsx2/releases/latest/download/pcsx2-zdxsv-macos.tar.xz">ダウンロード (macOS)</a></div>

### 2. 展開して移動する

ダウンロードしたファイルをダブルクリックすると、ダウンロードフォルダに `PCSX2-zdxsv-...` の app ができます。
この app を、左の「アプリケーション」にドラッグして移動します。

{% include shot.html file="mac-applications.png" alt="PCSX2-zdxsv の app をアプリケーションにドラッグする" %}

### 3. 開くのを許可する

アプリケーションフォルダの app をダブルクリックします。
「開いていません」と出たら「完了」を押します。

{% include shot.html file="mac-blocked.png" alt="開いていません の画面で「完了」を押す" %}

システム設定 → プライバシーとセキュリティ を開き、下のほうにある「このまま開く」を押します。
もう一度確認が出たら「このまま開く」を押します。

{% include shot.html file="mac-gatekeeper.png" alt="プライバシーとセキュリティの「このまま開く」を押す" %}
