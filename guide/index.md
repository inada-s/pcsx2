# PCSX2 for zdxsv セットアップガイド

PS2 の『機動戦士ガンダム ガンダムVS.Zガンダム』(2004, 日本版) を PC で動かし、
zdxsv サーバーでオンライン対戦するまでの手順です。上から順に進めてください。

## 用意するもの

- Windows 10 または 11 (64 ビット) の PC、または Mac (Apple シリコン / Intel)
- **PS2 の BIOS ファイル**: 自分の PS2 本体から吸い出したもの。
  吸い出し方: [pcsx2.net の BIOS ガイド (英語)](https://pcsx2.net/docs/setup/bios/)
- **ゲームのディスクイメージ (ISO)**: 自分のゲームディスクから作ったもの。
  作り方: [pcsx2.net のディスク吸い出しガイド (英語)](https://pcsx2.net/docs/setup/dumping)
- **Discord のアカウント**: オンライン対戦のサインインに使います。
- ゲームパッド

BIOS とゲームは、それぞれ専用のフォルダを作って入れておきます
(例: `C:\Games\PS2\bios` と `C:\Games\PS2\games`)。
初回設定でこのフォルダを選びます。

BIOS とゲームはこのガイドでは配布しません。
