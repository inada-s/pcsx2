# Changes from upstream PCSX2

What this fork changes in PCSX2's own code, against the fork point in
upstream ([PCSX2/pcsx2](https://github.com/PCSX2/pcsx2) `master`). The
features are in [features.md](features.md), their options in
[options.md](options.md).

## Fork point

- The merge base with upstream `master`; while that is older than
  `fd9d310cc` (upstream rewrote the commits the fork started from), `fd9d310cc`.
  `tools/zdxsv/upstream_spots.py` picks it:

  ```
  git fetch https://github.com/PCSX2/pcsx2.git master
  git diff --stat fd9d310cc zdxsv-master -- . ':!3rdparty' ':!pcsx2/Zdxsv' ':!pcsx2-qt/Zdxsv'
  ```

- An upstream merge moves it; this page names files and functions, not
  lines.
